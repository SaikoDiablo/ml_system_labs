# Machine Learning Systems Labs

Individual laboratory assignments for the Machine Learning Systems course.

## Topics

- Reproducible machine learning experiments
- Model accuracy and benchmarking
- Inference performance
- Memory and storage efficiency
- Model deployment and optimization

## Environment

- Python 3.11.8
- Dependencies pinned in requirements.txt

## Structure

Each lab contains source code, results, and a report.

The final project includes a README, data card, and model card.
